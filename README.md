# smt4-60fps

A 60 fps patch for Shin Megami Tensei IV (3DS). Game logic stays at 30 Hz; the in-between frames are interpolated.

- Releases: `releases/`. Each zip has a README with install steps.
- Building: see `CLAUDE.md`.
- Debugging and reverse-engineering setup: `docs/RE_SETUP.md`.

`game/` and `re/` contain material derived from the game itself. Keep them private.
